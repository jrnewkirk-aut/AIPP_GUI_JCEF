# AIPP M7 Production Workspace Shell

M7 separates the qualification harness from the production engineering workspace. The production launcher is `app/aipp_main.sce`; the qualification launcher remains `app/main.sce`.

The production workspace provides three persistent primary areas: Input deck editor, Run time, and Outputs. Existing accepted editor modules remain modular and are hosted under the editor area. Runtime and Outputs are structured placeholders for later live integration.
