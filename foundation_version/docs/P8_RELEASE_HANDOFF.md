# P8.5 Release Handoff

## Accepted baseline
The accepted implementation source is the P8.4 package identified in the evidence index. Use the P8.5 package as the complete Pillar 8 governance and evidence handoff.

## Operating rules
- Begin changes from the latest accepted package and verify SHA-256.
- Preserve application-owned roots during foundation upgrades.
- Replace foundation modules as a complete coherent set.
- Keep modular source authoritative; generated bundles are outputs.
- Require feature-parity evidence and the full live regression.
- Retain rollback packages and exported protocol results.
