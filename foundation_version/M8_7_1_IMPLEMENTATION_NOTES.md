# M8.7.1 Contextual Workspace Implementation

- Collapsible deck navigator, closed by default.
- Full-width topology as the default active work surface.
- Modeless right contextual editor drawer.
- Properties and Raw tabs retain the accepted M8.7 native inspector model.
- Chamber Pyros and Filters tabs mount the existing accepted M4/M5 editor DOM and view modules.
- Dirty property edits are protected when the drawer is dismissed.
- Legacy editors are no longer stacked below the topology.
- Table, Raw JSON, and Validation remain single active workspace placeholders pending their dedicated milestones.

## Candidate 02 correction

- Contextual workspace binding now exits cleanly on the qualification/test surface, where production-only workspace controls are intentionally absent.
- The navigator expansion control now uses the explicit visible label `Deck navigator` instead of relying on a menu glyph.
